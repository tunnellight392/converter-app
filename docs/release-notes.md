```
Search, copy and a converter that remembers where you left off.
```

### Changes in this release
- **Search** on the home screen, matching category names and unit names/symbols; the
  tile shows which unit matched. Drag-to-reorder is disabled while filtering.
- **Long-press to copy** a converted value, with a one-time tip on first open.
- **Last value per category** restored on reopen.
- **Decimal places** — a per-category default (Pay = 2) plus a user override in the
  converter's overflow menu, persisted per category.
- **Pay work week** — hours per week is now an input (1–168, default 40) that rebuilds
  the hourly rate and the on-screen note.
